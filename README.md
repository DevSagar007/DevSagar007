## 👨‍💻 About Me

I’m **Md Sagor Hossen**, a frontend developer from **Dhaka, Bangladesh**, with **4+ years of professional experience** building responsive, accessible, and high-performance web interfaces.

I specialize in converting **Figma, Adobe XD, and Photoshop designs** into pixel-perfect websites and scalable web applications. I enjoy creating reusable components, integrating REST APIs, improving performance, and delivering smooth user experiences across devices and browsers.

- 💼 Frontend Web Developer at **TDevs**
- 🎓 Studying **B.Sc. in Computer Science & Engineering**
- 🚀 Completed **20+ frontend and web application projects**
- 🧩 Experienced with **React.js, Next.js, TypeScript, Redux Toolkit, RTK Query, and TanStack Query**
- 🔌 Skilled in **REST API integration, JWT authentication, Firebase authentication, Stripe, and PayPal**
- 🎯 Focused on clean architecture, maintainable code, accessibility, SEO, and Core Web Vitals
