## 👨‍💻 About Me

I’m **Md Sagor Hossen**, a **Frontend-Focused Full-Stack Engineer** from **Dhaka, Bangladesh**, with **4+ years of experience** building responsive, scalable, and user-focused web applications.

My strongest expertise is in **React.js, Next.js, TypeScript, Redux, TanStack Query, and Tailwind CSS**, with experience in **React Native** for mobile apps. I also build backend systems with **Node.js, Express.js, REST APIs, JWT authentication, MongoDB, and PostgreSQL**, covering everything from API integration and database operations to validation and deployment.

- 💼 Frontend-Focused Full-Stack Engineer at **TDevs**
- 🚀 Completed **20+ projects**: web applications, HTML templates, and API implementations
- 🎓 Studying **B.Sc. in CSE** at Atish Dipankar University of Science & Technology
- 🧩 Frontend: React.js, Next.js, TypeScript, Redux Toolkit, RTK Query, TanStack Query, Angular, Vue.js
- 🔌 Backend: Node.js, Express.js, NestJS, REST APIs, JWT, PostgreSQL, MongoDB, Redis, Firebase

- 🔨 Currently building **MarketFlow**, an all-in-one digital marketing & automation SaaS
